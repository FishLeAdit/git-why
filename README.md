# git-why

Ask *why* an open-source repo changed and get an answer that links to the PRs, issues and commits behind it. Search and answering run entirely in your browser: no backend, no API key.

Default target: [`MIC-DKFZ/nnUNet`](https://github.com/MIC-DKFZ/nnUNet) (set in `config.json`).

> Work in progress. See [PLAN.md](PLAN.md) and [CHECKLIST.md](CHECKLIST.md).

## Develop

```sh
npm install
npm run dev
```
